# Числа и строки

Базовые скалярные типы Python: целые и дробные числа, строки и булевы значения.

## Числа

```python
age = 27          # int
price = 19.99     # float
total = age + price
```

Целочисленное деление `//`, остаток `%`, степень `**`:

```python
7 // 2   # 3
7 % 2    # 1
2 ** 10  # 1024
```

## Строки

Строки неизменяемы. Форматирование через f-строки:

```python
name = "Ада"
greeting = f"Привет, {name}!"
```

Полезные методы: `strip()`, `lower()`, `split()`, `replace()`.
