# Что такое Python

**Python** — высокоуровневый язык программирования общего назначения с акцентом на читаемость кода. Он используется в веб-разработке, анализе данных, машинном обучении и автоматизации.

## Почему Python?

- Простой и единообразный синтаксис
- Огромная стандартная библиотека
- Активное сообщество и множество учебных материалов

## Первая программа

Классика жанра — одна строка:

```python
print("Привет, мир!")
```

Запустите файл интерпретатором:

```bash
python hello.py
```

> Python исполняет код сверху вниз, поэтому результат появится сразу в консоли.
