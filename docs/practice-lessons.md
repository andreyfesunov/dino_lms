# Практические занятия

Занятие типа `practice` задаётся в `config.toml` bundle курса. Текст задания находится в Markdown-файле занятия, а материалы — в папке главы.

```toml
[[chapters]]
id = "portfolio"
title = "Портфолио"
open_by_default = true
lessons = [
  { id = "landing", title = "Лендинг для портфолио", type = "practice", duration_min = 45, attachments = ["brief.pdf", "wireframe.fig"] },
]
```

Для примера выше в bundle должны быть файлы:

```text
portfolio/landing.md
portfolio/brief.pdf
portfolio/wireframe.fig
```

В `attachments` указываются имена файлов в папке главы без вложенных путей. LMS проверяет наличие материалов при загрузке bundle и выдаёт их только пользователям с доступом к главе.

Студент сдаёт обязательную ссылку на проект; сообщение и отчёт необязательны. Преподаватель или администратор принимает работу либо запрашивает доработку. После запроса доработки студент может отправить следующую попытку. Все попытки и отзывы сохраняются; практика отмечается пройденной после принятия.
