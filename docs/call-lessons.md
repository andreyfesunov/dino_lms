# Занятия со звонком

Занятия описываются в `config.toml` курса. Чтобы добавить звонок, объявите его внутри нужной главы:

```toml
[[chapters.lessons]]
id = "consultation"
title = "Консультация с преподавателем"
type = "call"
```

Markdown-файл для звонка не нужен. У существующих занятий без `type` сохраняется тип `article`.

1. Администратор открывает занятие, выбирает преподавателя в настройках звонка и сохраняет назначение. В списке доступны преподаватели с активной учётной записью и заполненными именем и фамилией.
2. Преподаватель задаёт длительность звонка в настройках занятия, а доступность — в общем шаблоне расписания. Шаблон задаёт интервалы по дням недели, часовой пояс и горизонт публикации (по умолчанию 12 недель). Исключение закрывает отдельную дату или заменяет интервалы только на неё.
3. Студент выбирает дату в календаре, затем доступное время и подтверждает запись. Время отображается в часовом поясе его браузера. Пересекающиеся звонки преподавателя или студента исключаются между всеми курсами.
4. В разделе «Звонки» участники видят свои записи; администратор видит все. До начала звонка студент может перенести его в свободный слот или отменить. Преподаватель может перенести звонок на любое свободное будущее время и указать ссылку на встречу.
5. После окончания преподаватель отмечает звонок проведённым. Это засчитывает занятие в прогрессе студента и закрывает повторную запись на него.

Изменение окон или длительности не меняет существующие записи. Для смены преподавателя сначала отмените незавершённые звонки; прежние окна не переходят новому преподавателю. Для удаления преподавателя снимите его назначения и отмените незавершённые звонки. Записи в истории сохраняют названия и имена после удаления участников или занятия из каталога.

Уведомления доступны на страницах приложения. Отправки писем и автоматического создания видеовстреч нет.

Шаблон преподавателя читается и сохраняется через `GET` и `PUT /api/calls/schedule`; сохранение требует актуального поля `version`. Настройки занятия и доступные слоты расположены под `/api/courses/{course}/{chapter}/{lesson}/calls`. Список записей — `GET /api/calls`, действия над записью — `POST /api/calls/{id}` (`reschedule`, `cancel`, `link`, `complete`). Время записи передаётся в секундах Unix. При конфликте версии или занятом слоте сервер возвращает HTTP 409.

При обновлении старые разовые окна доступности удаляются; уже созданные записи и история звонков сохраняются. Преподаватель заново задаёт доступность в общем шаблоне.
