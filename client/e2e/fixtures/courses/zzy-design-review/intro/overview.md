# Как устроен курс

Материалы курса сгруппированы по темам. Изучайте их в удобном темпе и отмечайте пройденные занятия.

## Первая программа

```typescript
const greeting: string = "Привет, мир!";
console.log(greeting);
```

> На созвоне обсудим вопросы и разберём написанный код.

## План работы

1. Изучите материалы главы.
2. Выполните практическое задание.
3. Забронируйте время для обсуждения.

| Раздел | Формат |
| --- | --- |
| Материалы | Статьи и документация |
| Обратная связь | Индивидуальный созвон |

Подробности можно найти в [документации TypeScript](https://www.typescriptlang.org/docs/).
